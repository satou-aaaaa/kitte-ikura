# 切手いくら？（kitte-ikura）

この手紙、切手はいくら？ 封筒の大きさ・厚さ・重さから、郵便料金を当てる1日5問の学習ゲーム。定形・定形外（規格内・規格外）・はがき・往復はがき・速達・特定記録・書留・スマートレター・レターパックを扱います。正解したら「どの種類の郵便？」も選びます。

遊ぶ：https://satou-aaaaa.github.io/kitte-ikura/

- 料金と大きさの決まりは、日本郵便の料金表で確かめた数字だけ（2026-11-17 に読んだ。税込）。
  - [手紙・はがきの料金](https://www.post.japanpost.jp/send/fee/kokunai/one_two.html)
  - [手紙・はがきの大きさ・重さ](https://www.post.japanpost.jp/service/standard/one_size.html)
  - [オプションサービスの料金](https://www.post.japanpost.jp/send/fee/kokunai/option.html)
  - [はがき](https://www.post.japanpost.jp/service/send/domestic/mail/postcard/index.html)
- 郵便物の大きさ・重さは練習用の作り話です。公式の情報の代わりではありません。料金は変わることがあるので、出す前に日本郵便の料金表で確かめてください。
- 記録は遊ぶ人のブラウザ（localStorage）にだけ残ります。記録を外へ送ることはありません（外から読むのは、見やすさの設定で選んだときの Google Fonts の文字だけ）。好きなだけ遊べます（回数制限なし）。
